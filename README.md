# Sistema de Gestión de Biblioteca

## Descripción

Sistema de escritorio desarrollado en Java para gestionar el catálogo de una biblioteca.

La aplicación permite registrar libros, visualizar todos los libros, filtrar libros por autor y eliminar libros registrados.

## Integrantes

- Santiago Valencia

## Funcionalidades

- Registrar nuevos libros.
- Mostrar todos los libros registrados.
- Filtrar libros por autor.
- Eliminar libros seleccionados.
- Validar campos obligatorios.
- Validar códigos ISBN únicos.
- Validar año de publicación.
- Validar cantidad de copias.
- Ordenar libros por título.
- Contar libros registrados.

## Tecnologías utilizadas

- Java
- Java Swing
- IntelliJ IDEA
- Git
- GitHub
