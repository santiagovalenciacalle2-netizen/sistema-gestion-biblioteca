# Sistema de Gestión de Biblioteca

## Descripción

Sistema de escritorio desarrollado en Java y Java Swing para gestionar el catálogo de una biblioteca.

## Integrante

- Santiago Valencia

## Funcionalidades

- Registrar libros.
- Mostrar todos los libros.
- Filtrar libros por autor.
- Eliminar libros.
- Validar campos obligatorios.
- Validar códigos ISBN únicos.
- Validar año de publicación.
- Validar cantidad de copias.
- Ordenar libros por título.
- Contar libros registrados.

## Tecnologías

- Java
- Java Swing
- IntelliJ IDEA
- Git
- GitHub

## Ejecución

1. Abrir el proyecto en IntelliJ IDEA.
2. Configurar un JDK.
3. Abrir `Main.java`.
4. Ejecutar el método `main`.
5. Se abrirá la ventana de la biblioteca.
